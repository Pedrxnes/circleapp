# Agent Instructions

- All repository text must be en-US, including code comments, commit messages and documentation. User-facing strings are the exception: they live in `apps/desktop/src/shared/i18n.ts` and ship in both English and Brazilian Portuguese.
- Circle is an Electron desktop app for Windows (Linux builds are best-effort). Its source lives in `apps/desktop`.
- Run `cd apps/desktop && npm run check` (typecheck, build, tests) for the required verification. Two TypeScript projects are checked: `tsconfig.json` covers main, preload, shared and tests; `tsconfig.renderer.json` covers the React renderers.
- `src/shared/` must stay importable from both processes. The two exceptions, `png.ts` and `orb-icon.ts`, use Node APIs and are excluded from the renderer project — do not import them from a renderer.
- The floating orb is a transparent, click-through window. The main process hit-tests nothing itself: the renderer decides when the pointer is over the orb or the open panel and calls `circle:set-interactive`, which flips `setIgnoreMouseEvents`. Keep that contract when changing orb interaction.
- Orb placement lives in `src/main/layout.ts` and is deliberately free of Electron imports so it stays unit-testable. Add cases to `src/test/layout.test.ts` when changing it.
- Dragging is driven from the main process by polling the OS cursor, because a frameless window stops receiving pointer events once the cursor leaves its bounds. The release must persist the tracked centre, not the window bounds: crossing the middle of the screen flips the panel anchor and moves the orb inside its own box.
- Usage comes from `https://api.anthropic.com/api/oauth/usage` with the OAuth token Claude Code stores in `~/.claude/.credentials.json`. Circle never writes to that file and never refreshes the token itself — Claude Code owns it, and an expired token is reported to the user instead.
- The model breakdown comes from Claude Code's transcripts (`projects/**/*.jsonl`), read by `src/main/transcripts.ts`: only model, timestamp and token counts are kept, never content. Replies are deduplicated by message and request id (Claude Code logs a reply once per content block and copies history into resumed sessions) and weighted by API price from `src/shared/models.ts`; update its price table when Anthropic ships a model at a new price. Files are read incrementally from the last complete line, so keep that offset logic intact.
- The trend chart's SVG is stretched horizontally (`preserveAspectRatio="none"`), so anything round drawn inside it comes out as an ellipse. Hover dots, peak markers and the tooltip are HTML positioned over the plot with `src/shared/chart.ts`, which is the one coordinate system both layers share.
- Never commit credentials, `dist/`, `release/` or `node_modules/`. `resources/icon.png` is a static designed asset cropped from `icone_circle_novo.jfif`; `scripts/generate-icon.cjs` only checks it exists. It is the window, taskbar, notification and installer icon and the Settings header logo. The tray keeps the live ring from `renderOrbIcon`.
- Windows takes the taskbar button icon from the app the AppUserModelID resolves to, not from the window icon, so without an installed shortcut (`npm run dev`) it shows electron.exe's. `setTaskbarDetails` gives the Settings window a relaunch icon, which the shell only reads from a real file: `resources/icon.ico` in dev, the exe in a packaged build. Rebuild `icon.ico` (16–256 px) whenever `icon.png` changes.
- Settings are validated on every read by `normalizeSettings`, so a hand-edited or corrupt `settings.json` can never crash the app. Preserve that when adding a setting: add it to `Settings`, `DEFAULT_SETTINGS` and `normalizeSettings` together.
- All IPC handlers must call `requireTrusted`. Renderers stay sandboxed with `contextIsolation` on and reach the main process only through the frozen `window.circle` bridge.
- `npm run capture:docs` regenerates the screenshots in `docs/` from the real renderers with a seeded reading (no Claude Code login needed); it needs a display, so wrap it in `xvfb-run -a` on a headless machine. Re-run it whenever a UI change makes the README images wrong, and commit the regenerated PNGs.
- `CIRCLE_SMOKE=1` boots the real app, seeds a reading, screenshots both windows and exits. It is the cheapest check that the main process and both renderers still start.
- Renderer screenshots must come from a *shown* window: a hidden BrowserWindow produces no new compositor frames, so `capturePage` returns a stale image and `sendInputEvent` never reaches the page.
- `.content` in the settings window sets `grid-auto-rows: max-content`. Without it the grid shares its definite height between the sections and `overflow: hidden` silently clips rows off the bottom of each one.
